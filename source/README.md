# Портфолио — главная страница (пакет для переноса)

Дата сборки: 11.11.2026. Автор макета и проекта: Андрей Кравченко.

## Что внутри

```
index.html                 главная страница целиком (один файл, открывается двойным кликом, ничего не требует)
example-other-page.html    пример «второй страницы», собранной из папки shared (проверено, работает)
shared/                    общие куски для склейки страниц
  tokens.css               цвета, шрифт, база, колонка .page (498 px, блоки через 80 px)
  font.css                 @font-face Medeo Mono
  pill.css  pill.js        пилюля навигации и её поведение
  pill-main.html           разметка пилюли для главной
  pill-sub.html            разметка пилюли для других страниц
  smooth-wheel.js          плавный скролл колесом/трекпадом
assets/                    исходные файлы: шрифт, иконки, лого кейсов, анимированные экраны, линейка, баннер, кнопки футера, портрет
```

`index.html` — единственный источник правды по главной. Файлы в `shared/` вынуты из неё. Если правите пилюлю или скролл, правьте в обоих местах или переведите `index.html` на `shared/`.

## Как склеить с другими страницами

1. Положить новую страницу в корень пакета рядом с `index.html` (пути в partial'ах начинаются с `assets/…`; если страница лежит глубже, поправьте пути).
2. В `<head>`: `meta viewport` с `viewport-fit=cover` (обязательно, иначе на iPhone не сработают отступы под вырез), затем `shared/font.css`, `shared/tokens.css`, `shared/pill.css`.
3. `<body data-pill="sub">` (для других страниц) или `"main"` (главная) и сразу под ним содержимое `shared/pill-sub.html` / `pill-main.html`.
4. Контент в `<main class="page">`: колонка 498 px, блоки через 80 px.
5. В конце страницы: `shared/smooth-wheel.js`, затем `shared/pill.js`.
6. Пример: `example-other-page.html`.

## Пилюля

**Когда видна**
| Событие | Результат |
|---|---|
| `scrollY ≤ 2 px` | видна |
| любой скролл от верха | скрывается; новый скролл скрывает и при наведении |
| курсор в зоне места пилюли (её прямоугольник + 10 px по бокам и снизу, от верха окна) | появляется |
| курсор ушёл из зоны или за окно | скрывается |
| фокус с клавиатуры на её ссылках | видна |
| сенсорный экран (`hover: none`): скролл вверх > 4 px / вниз > 4 px | появляется / скрывается |

Анимация только прозрачностью, без движения: исчезновение 0,08 с linear, появление 0,4 с ease. В скрытом состоянии `pointer-events: none`. Место пилюли отмечает невидимый `.pill-slot`. Константы в начале `pill.js`: `AT_TOP`, `HOVER_PAD`, `TOUCH_STEP`.

**Кнопки:** круг 30,67 px, иконка 19,63 px, зазор 8 px, отступ от рамки 2,83 px. Hover и `:focus-visible`: фон `#000511`, иконка инвертируется в белую (`filter: invert(1)`), 0,15 с ease; при фокусе добавляется обводка 2 px `#0b3463`. Состояний «нажато» и «текущая страница» нет. Иконки должны быть чёрными.

**Два вида** (`<body data-pill="main|sub">`): main 498 px, иконки справа (Работы, Образование, Telegram последним); sub 628 px, слева «назад» и мини-голова, справа Telegram.

## Плавный скролл (smooth-wheel.js)

Перехватывает колесо и тянет страницу к цели с экспоненциальным торможением. Клавиатура, полоса прокрутки и тач остаются нативными. Не перехватывает: `Ctrl`+колесо, горизонтальные жесты, reduced motion, всё внутри `[data-native-scroll]` (ставьте на модалки и блоки со своей прокруткой).

| Константа | Значение | Что делает |
|---|---|---|
| `TAU` | 90 мс | вязкость; больше значит плавнее и дольше (рабочий диапазон 60–140) |
| `LINE_PX` | 16 | пикселей на строку для колёс в режиме строк |
| `MAX_DT` | 50 мс | защита от скачков при просадке кадров |
| `STOP_PX` | 0,5 | порог остановки |

Плавный скролл по якорям живёт только в `index.html` (там же `data-pill-gap="32"` у иконки «Работы»: нижний край пилюли на 32 px выше первого кейса).

## Что есть только на главной (в `index.html`)

- **Шапка:** имя (h1, SemiBold 600), должность, био с ручными переносами, ссылка «Написать мне» (последняя строка абзаца).
- **Баннер «Ещё в разработке…»:** статичный, 498×64, отступы 80 px.
- **Кейсы** (`#work`): данные в массиве `items` (дата, название, клиент, роль, платформа, есть ли экран), иконки в `ICONS` по порядку. Рамка логотипа 126×80 из уголков, по hover на весь кейс (`.case:hover`): уголки 1→2 px и 17→26 px, 170 мс ease-in. Длина уголков подобрана по скриншоту, из Figma не читалась.
- **Анимированные экраны** (Cloudlink, «Тариф») внутри линеек: SMIL-анимация 5 с играет, пока курсор над кейсом, после ухода доигрывает цикл и замирает на первом кадре. Играют только при наведении мышью.
- **2013—2017 и Образование** (`#edu`): всё по центру. Все веса 400, кроме h1.
- **Портрет:** слева от колонки, `position: fixed`. Canvas из `portrait-dissolve.js` (в API добавлены `draw` и `dur`, оригинал в `assets/portrait/`). Растворяется, когда нижний край последнего кейса поднялся выше верха портрета; при скролле назад собирается обратно. Скрыт на экранах уже 720 px.
- **Футер:** две анимированные кнопки 88×88 одна под другой с отступом 80 px: профиль ведёт в Telegram (https://t.me/floatingpatterns), диафрагма в Instagram (https://www.instagram.com/floatingpatterns/).

## Токены

Цвета: фон `#fffef7`, текст `#000511`, ссылка `#0b3463`, рамка логотипа и текст образования `#101827`. Только светлая тема.
Шрифт: Medeo Mono (вариативный). Размеры: био 14/20, кейсы 17, должность 20 с интервалом 1 px, годы образования 28, h1 32,25/58 капсом. Лицензию на шрифт проверьте сами, он встроен в `index.html` и лежит в `assets/fonts/`.
Отступы: между блоками страницы 80 px, между кейсами 60 px.

## Допущения и открытые вопросы

- Часть значений из Figma не читалась (лимит вызовов Starter): длина уголков рамки, точные отступы пилюли сверены только по замерам и скриншотам.
- В пилюле нет состояний «нажато» и «текущая страница»: добавлять по мере появления страниц.
- Hover-анимации (рамка логотипа, экраны) на сенсорных экранах не работают.
- У кейсов без экрана (все кроме Cloudlink и «Тариф») рамки с линейками нет.

## Промпт для нового чата

> Прикладываю пакет страницы портфолио (zip). `index.html` — главная, `shared/` — общие куски (пилюля, плавный скролл, токены, шрифт), `README.md` описывает поведение. Нужно сделать новую страницу в том же стиле и подключить к ней shared-файлы: `<body data-pill="sub">`, partial `shared/pill-sub.html`, колонка `.page`. Не менять токены, шрифт и поведение пилюли без моей просьбы. Весь текст Regular (400), кроме h1.
