# Портфолио — Андрей Кравченко

Статический сайт без сборки, публикуется через GitHub Pages.

## Структура
```
index.html        главная (один файл, всё встроено)
cloudlink/        кейс «Cloudlink: реинжиниринг и редизайн» (index.html, styles.css, script.js, assets/)
tarif/            кейс «Дизайн и запуск G2B «Тариф»» (index.html, assets/)
cursors/          курсоры (PNG 1x и @2x), исходники в cursors/src/*.svg
footer-portrait.svg  портрет для футера (векторный, 68×90, без фона)
footer.css        футер кейсов: кнопка Telegram и портрет, отступы 80 px как на главной
mobile.css        мобильная версия (до 720 px): пилюля 44 px, портрет на уровне пилюли, карточки кейсов, кнопка закрытия картинки, футер
cursors.css       правила курсоров для всех страниц (стрелка, палец, крест, чашка на время перехода)
transition.css/js анимации переходов между страницами
source/           исходный пакет главной: shared/ (пилюля, токены, плавный скролл), example-other-page.html, README с описанием поведения
.nojekyll         отключает Jekyll на GitHub Pages
```

## Переходы
- Главная → кейс: клик по Cloudlink или «Тариф» (ссылки `cloudlink/`, `tarif/`).
- Кейс → главная: кнопка «назад» в пилюле (`../`).
- Все пути относительные, поэтому сайт работает и на `https://<логин>.github.io/<репозиторий>/`, и на своём домене.

## Публикация на GitHub Pages (аккаунт https://github.com/floatingpatterns)
Репозиторий с именем `floatingpatterns.github.io` откроется сразу на `https://floatingpatterns.github.io/`; любое другое имя (например `portfolio`) — на `https://floatingpatterns.github.io/portfolio/`. Пути в файлах относительные, подходит оба варианта.

Через терминал (из этой папки, где лежит `index.html`):
```
git init -b main
git add .
git commit -m "Portfolio site"
git remote add origin https://github.com/floatingpatterns/floatingpatterns.github.io.git
git push -u origin main
```
(репозиторий сначала нужно создать на GitHub: New repository, пустой, без README).

Без терминала: создать репозиторий, нажать «uploading an existing file» и перетащить внутрь все файлы из этой папки (не саму папку `site`, а её содержимое, включая `.nojekyll`).

Затем Settings → Pages → Deploy from a branch → `main` / `/ (root)` → Save. Через 1–2 минуты сайт откроется.

## Свой домен
Settings → Pages → Custom domain. В DNS: четыре A-записи на 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153 и CNAME для `www` на `<логин>.github.io`. После обновления DNS включите Enforce HTTPS.

## Новые кейсы
Новая страница = папка `имя/index.html` + строка-ссылка в массиве `items` в `index.html` (см. словарь `href` в цикле построения списка). Шаблон страницы: `source/example-other-page.html`.

## Портрет на главной
На первом экране базовый портрет (canvas 80×90, пиксель 2 px). Когда доезжаешь до первого кликабельного кейса, он квадрат за квадратом превращается в иконку с лупой (около 0,65 с); после последнего кликабельного кейса — обратно; при скролле вверх те же шаги в обратную сторону. Когда проехал самый последний фрейм, портрет растворяется пикселями, как раньше. Оба рисунка — векторные контуры в `index.html` (`D` — базовый портрет, `ALT` — иконка с лупой). Кликабельные кейсы определяются автоматически: это кейсы со ссылкой. Пороги задаёт функция `wantMorph()`.

## Адаптив
Три режима по ширине экрана (всё в `mobile.css`, переменная `--col` — ширина колонки контента главной):
- **от 708 px** — десктоп: колонка 498 px по центру, портрет в левом поле;
- **553–707 px** — колонка сужается плавно (экран − 210 px, от 498 до 343 px), портрет остаётся в левом поле;
- **до 552 px** — телефон: портрет 39×44 уходит в строку пилюли, колонка почти во всю ширину (отступы 16 px), пилюля 44 px, футер с отступами 56 px.

Карточки кейсов на главной становятся компактными, когда колонка уже 440 px (контейнерный запрос; то же значение `COMPACT_AT` в скрипте главной): шрифт 15 px, квадратная рамка с логотипом по высоте текста. Рамка со схемой и её линейки масштабируются от ширины колонки (переменная `--k`). Пилюля и портрет всегда по ширине колонки контента. Горизонтального скролла нет (скроллятся только полосы скриншотов).

Пилюля: на телефонной раскладке и на тач-устройствах прячется при скролле вниз (после 6 px) и появляется при скролле вверх (после 14 px); на десктопе — по наведению. Между страницами пилюля плавно меняет ширину и положение, по центру экрана на время перехода стоит чашка (на устройствах без курсора). В увеличенной картинке на телефоне есть кнопка закрытия.

## Футеры
На главной портрет стоит под круглой кнопкой Telegram (кнопка Instagram скрыта атрибутом `hidden` в `index.html`, чтобы вернуть — убрать атрибут), на кейсах — под кнопкой Telegram. Кнопки 72 px (компромисс по весу с портретом 68×90; было 88 px), между элементами и под портретом 80 px. Портрет — `footer-portrait.svg` (трассировка с картинки, цвет `#101827`, чтобы сменить цвет, правьте `fill`).

## Курсоры
Стиль «полосы»: полоса 2 / зазор 2 физических пикселя (на обычных экранах 1 px / 1 px), светлая подложка `#fffef7`. Стрелка — по умолчанию, палец — кнопки, ссылки, картинки и фреймы, крест — закрытие увеличенной картинки, чашка — на время перехода между страницами. Нарисованы под Retina (1 единица = 1 физ. пиксель), на обычных мониторах полосы 1 px / 1 px, тоже чётко. Чтобы поменять курсор, правьте SVG в `cursors/src/` и пересохраните PNG.
